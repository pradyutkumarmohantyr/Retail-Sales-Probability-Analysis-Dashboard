# Retail Sales & Profitability Analysis

A data analytics project analyzing retail transaction data to uncover sales trends, profitability drivers, and actionable business recommendations.

## Project Structure
- `notebooks/` — data cleaning, EDA, statistical analysis, and modeling
- `data/` — raw and processed datasets
- `database/` — SQLite database of the cleaned data
- `scripts/` — helper scripts to build/test the database
- `reports/` — executive summary of findings
- `dashboards/` — Power BI / Tableau dashboard files

## Key Tools
Python (pandas, numpy, scipy, scikit-learn, matplotlib), SQL, Power BI, Tableau Public
